## 0.3 - Security Audit

### Findings
- **HIGH**: Third-party tracking present (Meta Pixel + Google Tag) in `index.html` and `checkout/index.html`. This violates the -no data exfiltration / no telemetry- requirement and sends user activity to external services.
- **MEDIUM**: Client-side auth stub (`auth.js` and `www/auth.js`) uses localStorage and provides no server-side enforcement. Even though not currently wired into the UI, it is unsafe if re-enabled.
- **MEDIUM**: Access control functions (`pilot-gate.js`, `access-check.js`) rely on a local JSON store and shared token; no real user auth or RBAC. Not production-safe.
- **LOW**: `bot/secrets.env.template` includes credential placeholders. No real secrets committed, but ensure `.env` files never enter the repo.

### Secret/Key Exposure Check
- No plaintext private keys, mnemonics, or real API secrets found in source.
- Placeholder Firebase config present in `auth.js` and `www/auth.js` (non-functional by design).

### Hand-Rolled Crypto
- None detected. No crypto libraries or custom cryptography in current build.
